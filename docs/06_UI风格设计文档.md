# 06 UI风格设计文档

> 编制依据：`docs/05_设计文档总览.md`　|　适用范围：LibMS 全部前端界面
> 组件库基线：**Element Plus 2.14.5（Vue3 专用，不使用 Vue2 版 Element UI）**，风格定制通过 CSS 变量覆盖实现，不侵入组件源码。

---

## 一、设计定位

> **一句话调性：以"书卷墨青"为主色的清爽学术风后台管理界面——深色侧边导航立骨架、浅灰画布铺内容、白卡片承载信息，克制的色彩只留给状态与操作，让馆员与读者第一眼就感到"安静、有序、可信"。**

具体拆解为三条设计原则：

1. **信息优先**：界面色彩服务于业务状态（在借/逾期/欠费），装饰性元素为零；
2. **操作高效**：高频动作（借书/还书）始终处于视觉焦点区，表单步骤不超过一层弹窗；
3. **学术克制**：低饱和主色 + 大量留白，呼应图书馆场景的书卷气质，符合毕业设计答辩演示的严谨观感。

## 二、色彩体系

### 2.1 主色与辅色

| 角色 | 色值 | 名称 | 界面使用场景 |
|------|------|------|--------------|
| **主色 Primary** | `#2B6CB0` | 知识蓝 | 侧边导航选中态、主操作按钮（确认借出/保存）、链接文字、分页选中、ECharts 第一主色、面包屑当前页 |
| 主色浅阶 | `#EBF3FB` | 浅蓝底 | 表头背景、选中行高亮、Tag 浅色底（在借状态） |
| **辅色 Secondary** | `#2C7A7B` | 青墨绿 | 次级强调（读者身份标识、续借按钮）、ECharts 第二色（趋势图副系列） |
| **强调色 Accent** | `#C05621` | 暖赭橙 | 到期提醒角标、罚金金额数字、ECharts 第三色（占比图对比） |

> 主色定制方式：在 `src/styles/index.css` 中覆盖 `--el-color-primary` 及其 `light-3/5/7/8/9`、`dark-2` 派生变量（如 `--el-color-primary: #2B6CB0`），Element Plus 全组件自动继承，无需逐个组件改色。

## 三、字体与排版

**字体方案（系统字体栈，免安装、答辩零风险）：**

```css
font-family: "PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
```

> 说明：答辩环境为 Windows，微软雅黑必然存在；macOS 演示时自动回退苹方。论文中可表述为"采用跨平台系统字体栈，保证渲染一致性与加载性能"。

**字号层级规范：**

| 层级 | 字号/行高 | 字重 | 使用场景 |
|------|-----------|------|----------|
| H1 页面主标题 | 20px / 28px | 600 | 各页面顶部标题（如"图书档案管理"） |
| H2 卡片标题 | 16px / 24px | 600 | 卡片标题、弹窗标题、分组标题 |
| H3 小节标题 | 14px / 22px | 600 | 表单分组、面板小节 |
| 正文 Body | 14px / 22px | 400 | 表格数据、表单值、按钮文字（Element Plus 默认基准） |
| 辅助 Small | 12px / 20px | 400 | placeholder、时间戳、表格次级信息、Tag |
| 统计数字 | 28px / 36px | 600 | 数据总览卡片大数字（等宽数字 `font-variant-numeric: tabular-nums`） |

> 全局基准：正文 14px、行高 1.5 倍；中文字重只使用 400/600 两档，避免楷体/宋体混排。

## 四、间距与圆角

**间距规则（8px 网格体系）：**

| 级别 | 取值 | 使用场景 |
|------|------|----------|
| XS | 4px | 图标与文字间距、Tag 内边距 |
| S | 8px | 表单项之间、按钮组内间距 |
| M | 16px | 卡片内边距、检索栏与表格间距、表单 label 与控件纵向间距 |
| L | 24px | 页面四周留白、卡片之间纵向间距、数据总览卡片栅格间距 |
| XL | 32px | 页面主区块之间 |

布局栅格：侧边导航固定 `240px`；顶栏 `60px`；内容区左右留白 `24px`，最大宽度自适应；数据总览卡片行为 flex 等分布局（当前 5 张：图书品种 / 馆藏总册数 / 当前在借 / 注册读者 / 今日借还）。

**圆角规范：**

| 对象 | 圆角 | 说明 |
|------|------|------|
| 按钮、输入框、下拉 | `4px` | 与 Element Plus 默认一致，紧凑干练 |
| 卡片、弹窗 | `8px` | 柔和但不软塌 |
| Tag、状态徽标 | `4px`（或全圆角胶囊） | 状态标签统一胶囊形 `999px` |
| 头像 | `50%` | 圆形 |

**阴影（克制两档）：**

- 卡片常态：`box-shadow: 0 2px 12px rgba(0, 0, 0, 0.06);`
- 卡片 hover / 弹窗：`box-shadow: 0 4px 16px rgba(0, 0, 0, 0.10);`

## 五、组件风格倾向（Element Plus 定制方向）

| 组件 | 定制方向 |
|------|----------|
| **按钮** | 主操作用 primary 实心（确认借出/保存）；次操作用描边 Default（重置/取消）；危险操作 danger（删除/停用）；行内操作统一 `link` 文字按钮 + 间距 12px；同一页面实心主按钮**有且仅有一个** |
| **卡片** | 白底 + 8px 圆角 + 浅阴影 + 16px 内边距；卡片标题左侧加 3px × 16px 主色竖条装饰；数据总览卡片 = 图标（各自浅色底圆角方块）+ 数量 + 一级灰标题 |
| **表格** | 表头 `#F5F7FA` 底 + 600 字重；行高 52px（含内边距）；开启斑马纹与 hover 高亮；状态列统一用 `el-tag`（在借=warning、已还=info、已赔偿=danger，逾期标签=danger，罚金未缴=warning / 已缴=success）；操作列右对齐、固定右侧 |
| **表单** | label 右对齐、宽度 80–100px（常用 90px）；输入控件宽度按表单自适应（检索栏约 200px）；新增/编辑共用居中弹窗（图书/公告 640px、用户 560px、密码 480px，圆角 8px），删除等危险操作二次确认 |
| **弹窗与消息** | 结果反馈用 `ElMessage`（成功/错误各 3 秒自动消失）；借书成功同时展示应还日期；删除类操作必须 `ElMessageBox.confirm` 二次确认 |
| **导航** | 深墨蓝侧边栏 `#1F3552`（240px，可折叠至 64px 图标态）；菜单文字浅灰蓝 `#C0C8D4`、激活项主色背景 + 左侧 3px 主色指示条；顶栏含面包屑 + 右侧用户头像下拉（个人中心/退出） |
| **检索栏** | 卡片内"输入项 + 查询/重置按钮"单行布局，超出换行；查询主按钮在右下 |
| **分页** | 统一右下角：每页 10/20/50 条可选，展示"共 N 条" |
| **空状态** | `el-empty` 插画 + 一句话引导（"暂无借阅记录"） |
| **ECharts 图表** | 色序：`#2B6CB0 → #2C7A7B → #C05621 → #67C23A → #E6A23C`；折线平滑 + 区域 10% 渐变填充；占比图为环形饼图（42%–68%）、图例置底居中；借阅热度 TOP10 以表格呈现（无柱状图） |

## 六、规范落地方式（开发约束）

1. 全局样式入口 `src/styles/index.css`：引入字体栈、CSS 变量、Element Plus 主色覆盖，一次性生效；
2. 颜色**只允许引用 CSS 变量或本文档色值**，禁止组件内随意写死十六进制色（图表色序除外）；
3. 间距/圆角遵循第四节取值表，超出表内的值需先修订本文档；
4. 本文档为 6.2 原型设计（`docs/原型页面/`）与前端编码（`frontend/`）的视觉基准。
